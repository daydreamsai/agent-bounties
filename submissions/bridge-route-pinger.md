# bridge-route-pinger

## Agent Description

Bridge Route Pinger lists cross-chain bridge routes with fee and time estimates. Queries Mayan Finance, Wormhole Portal, and deBridge to find the cheapest and fastest transfer paths.

- **Protocol:** x402 enabled
