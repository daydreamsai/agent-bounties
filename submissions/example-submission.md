# Example Submission

This is a template for bounty submissions. Create a new file in this directory with your agent details.

## Required Information

1. **Agent Description** - What does your agent do?
2. **Live Deployment URL** - Must be deployed and reachable
3. **x402 Endpoint** - Payment gateway URL
4. **Acceptance Criteria** - How you met each criterion
5. **Solana Wallet** - For bounty payment

## File Naming

Name your file `your-agent-name.md` in the `submissions/` directory.

## Example Structure

See [fresh-markets-watch.md](./fresh-markets-watch.md) for a complete example.

## Submission Checklist

- [ ] Agent meets technical specifications
- [ ] Deployed on a domain
- [ ] Reachable via x402
- [ ] PR links to the bounty issue
