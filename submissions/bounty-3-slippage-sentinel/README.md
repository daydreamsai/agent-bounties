# Slippage Sentinel — Bounty #3

Estimate safe slippage tolerance for any swap route to prevent reverts.

## Features
- Multi-fee-tier analysis across Uniswap V3 pools
- Price impact calculation via dual-quote method
- Risk classification and recommended slippage
- Built with `@lucid-dreams/agent-kit` + `viem` + `zod`

## Setup
```bash
npm install
npm start
```
