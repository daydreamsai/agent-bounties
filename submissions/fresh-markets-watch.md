# Fresh Markets Watch - Submission

## Agent Description

Fresh Markets Watch is an AI agent that monitors AMM factory contracts across multiple EVM chains to detect and report new liquidity pairs/pools within seconds of creation. The agent is built using the `@lucid-dreams/agent-kit` framework and exposes an x402-compatible endpoint for real-time discovery.

## Live Deployment

- **URL**: `https://fresh-markets-watch.example.com`
- **x402 Payment Gateway**: `https://fresh-markets-watch.example.com/x402`
