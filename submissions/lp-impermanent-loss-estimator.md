# lp-impermanent-loss-estimator

## Agent Description

LP Impermanent Loss Estimator calculates impermanent loss and fee APR for LP positions using the constant-product AMM formula. Projects IL at various price divergence levels and estimates fee earnings from pool volume/TVL.
